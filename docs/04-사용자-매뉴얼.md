# 4. 사용자 매뉴얼

## 접속과 로그인
1. 브라우저에서 **https://profcys.web.app**에 접속합니다. QR코드로도 접속할 수 있습니다.
2. 관리자가 알려 준 **아이디와 임시 비밀번호**로 로그인합니다. 회원가입 기능은 없습니다.
3. 처음 로그인하면 **새 비밀번호를 설정**해야 합니다.
   - 12자 이상
   - 영문 대문자·소문자·숫자·특수문자 중 3종류 이상
   - 아이디가 포함되면 안 됩니다
4. 비밀번호를 5번 틀리면 15분 동안 로그인할 수 없습니다. 비밀번호를 잊었으면 관리자에게 초기화를 요청하세요.

## 대시보드
- 내가 사용할 수 있는 업무 서비스만 카드로 표시됩니다. 화면 크기와 서비스 수에 맞게 자동으로 배치됩니다.
- **검색**: 서비스 이름, 설명, 키워드, 카테고리로 찾을 수 있습니다.
- **필터**: 전체, 즐겨찾기, 최근 사용, 신규, 이용 가능, 카테고리별로 볼 수 있습니다.
- ☆를 누르면 즐겨찾기에 추가됩니다. 최근 사용한 서비스와 **NEW** 표시가 붙은 신규 서비스는 위쪽에 모여 보입니다.
- **접속** 버튼을 누르면 서비스가 새 탭에서 열립니다. 팝업이 차단되면 현재 탭에서 열립니다.
- 카드 상태 표시:
  - 이용 가능
  - 점검 중: 안내 문구 확인
  - 접근 제한: 권한이 필요하면 관리자에게 문의
- 🔔 알림에서 공지사항과 신규 서비스를 확인합니다.

## 보안 안내
- 60분 동안 사용하지 않으면 자동으로 로그아웃됩니다. 5분 전에 안내가 표시되며, **계속 사용**을 누르면 연장됩니다.
- 공용 PC에서는 반드시 우측 상단 메뉴에서 **로그아웃**하세요.
- 브라우저에 비밀번호를 저장하지 마세요. PROFCYS는 비밀번호를 저장하거나 조회하지 않습니다.

## 앱처럼 사용하기 (PWA)
- PC(Chrome·Edge): 주소창의 설치 아이콘을 누릅니다.
- Android: 메뉴에서 **홈 화면에 추가**를 누릅니다.
- iPhone(Safari): 공유 버튼에서 **홈 화면에 추가**를 누릅니다.

## 문의
로그인 화면과 도움말에 표시된 관리자 문의처로 연락하세요. 오류 화면에 **오류 코드**가 표시되면 함께 알려 주세요.
