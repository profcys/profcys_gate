- 실행일: 2026-11-26 (KST)
- 환경: Node.js, Vitest 4.1, Playwright Chromium (헤드리스)
- 대상: 실제 서버 코드(`apps-script/gateway-api`)를 Node vm에서 실행하되, Firestore·Firebase Auth·CacheService만 메모리 구현으로 대체했습니다.
- 표기 기준:
  - **PASS**: 실행해서 통과
  - **FAIL**: 실행해서 실패
  - **NOT TESTED**: 실행하지 않음
  - **BLOCKED**: 환경 제약으로 실행 불가
  - 실행하지 않은 항목은 PASS로 적지 않았습니다.

## 7.2 테스트 중 발견·수정한 결함

| # | 결함 | 발견 | 조치 |
|---|---|---|---|
| 1 | 강제 로그아웃 직후 같은 밀리초에 만든 세션이 폐기되지 않음 | 통합 | 폐기 기준 시각을 +1ms로 바꿈 |
| 2 | 실행 방식 "인증 연동 후 실행(SSO)"만 선택하면 인증 코드가 발급되지 않음 | 통합 | SSO 실행 방식에서도 코드 발급 |
| 3 | 조건 정책(RULES)이 OR로 평가되어 관리자 화면 안내("모두 충족")와 다름 | 단위 | AND 평가로 수정 (더 안전한 쪽) |
| 4 | 공통 모듈 `clientScript`에 `</script>` 문자열 주입 가능 | 통합 | 토큰 형식 검사 + `<`, `>` 이스케이프 |
| 5 | 변경 알림 구독 코드의 변수 선언 순서 오류로 사용자 대시보드가 빈 화면 | E2E | 선언 위치 수정 |
| 6 | 최초 비밀번호 변경 직후 대시보드가 "불러오는 중"에서 멈춤 | E2E | 변경 완료 시 다시 조회 |
| 7 | 팝업 차단 시 SSO 코드 없이 현재 탭으로 이동 | 코드 검토 | 현재 탭에서도 같은 방식으로 코드 전달 |
