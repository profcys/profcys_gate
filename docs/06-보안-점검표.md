## 남은 위험과 권고
1. 업무 Apps Script를 `enforce` 모드로 바꾸기 전까지는 기존 URL을 아는 사람이 포털을 거치지 않고 접속할 수 있습니다.
   기존 서비스 자체의 접근 설정에 따라 다릅니다. 포털 권한은 "카드 표시·실행 통제"일 뿐 완전한 차단은 아닙니다.
2. Apps Script 웹앱의 "모든 사용자" 액세스는 API 호출이 가능하다는 뜻입니다. 모든 기능은 서버 검증을 거칩니다.
   남용 시 일일 할당량이 소진될 수 있어(가용성 위험) 접속 기록 모니터링을 권장합니다.
3. 관리자 계정에는 고유하고 긴 비밀번호를 사용하고, 공용 PC에서 관리 작업을 하지 마세요.
